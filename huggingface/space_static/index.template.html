Multimodal Market AI — synthetic demo

Deterministic signals and a visual signal from a chart image are fused into one row per decision. Everything on this page is fake data, generated by open-source code.

Not a trading bot, not a signal service, not a promise of profit. The visual signal here is a deliberately simple mock, used to show how an image path, a visual feature and a fusion record fit together.

Reading the signals: +1 means a rule points one way, −1 the other way, and 0 means that rule is not voting. A final LONG or SHORT needs the deterministic result and the visual signal to agree; otherwise the decision is WAIT.

The three chart images

The mock visual adapter

In a real setup, a vision model would look at each chart image and answer with a direction. Here a small stand-in plays that part, so the demo runs anywhere with no model and no GPU. It does not read the image: it measures the price change over the last 12 closes (mock_visual_score) and turns it into +1 above +0.3%, −1 below −0.3%, and 0 in between. A real model would fill the same visual_signal column. It would first have to show that it adds information over a plain deterministic baseline.

Why it is built this way

  • Each row has a stable identity and a decision time.
  • Unavailable data is not invented.
  • Deterministic, numerical and visual sources stay separate enough to audit.
  • A visual model is optional: it has to prove it adds information over a plain baseline.
